  $o = $json | ConvertFrom-Json
  if ($o -isnot [Management.Automation.PSCustomObject]) { throw 'el mapa no es un objeto JSON' }
  $props = @($o.PSObject.Properties)
  $claves = (@($props | ForEach-Object { $_.Name }) | Sort-Object) -join ','

    if ($p.Value.Length -lt 32 -or $p.Value -match '\s') { throw "$($p.Name): menos de 32 caracteres o con espacios" }
    if (-not $vistos.Add($p.Value)) { throw 'hay secretos repetidos entre locales' }

## 8. Criterios de parada → rollback (§9)
Se para **sin discutir** si pasa cualquiera de estos:
1. 401 en el log del agente después de arrancarlo (5.2).
2. `last_error` no nulo **dos ciclos seguidos**, o `last_poll_at` quieto **más de 5 minutos** con el local abierto.
3. **Cualquier** factura con líneas duplicadas (6.3/6.4/§7) que no se explique contra el PoS.
4. Una factura cerrada en el PoS que **no llega en 3 ciclos**, o llega con otro total o con otra cantidad de líneas.
5. `ingest-ndf: excepción` o `no se pudo guardar el lote` en los logs del Edge.
6. «Enforce JWT verification» prendido y no se corrige con un redeploy (§5.1).
7. La prueba de humo no pasa en **30 minutos** desde la primera venta.
8. **Un 5xx o un timeout del Edge en 2 ciclos seguidos**, aunque el siguiente entre (el agente reintenta una vez cada
   5xx: un ciclo con sus dos intentos fallidos cuenta como uno).
9. **Un `200` con descartes** (`invalid > 0` o `problemas` no vacío, 6.5).
10. **Desfase** en la conciliación (7.3) que no se explica, o `last_factura > max_factura_vista`, o una `R` vieja de
    7.2 que el replay (7.4) no corrige.
11. El agente no vuelve a `Running` después de 5.2, o tarda más de 5 minutos.
