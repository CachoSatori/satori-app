# Prototipos de UI

Referencias visuales congeladas. **No se importan en la app** y **no se editan**: son la
meta contra la que se compara una pantalla, no código.

## `nomina-satori-v3.html` — FALTA

El prototipo `Nomina-Satori-v3.html` del SPEC-UI Empleados v3 (versión con
`A pagar = horas + 10% de servicio`) **no llegó a la sesión** que armó el piloto visual
(rama `claude/ui-salarios-nomina-v3-ghb3lw`, 2026-08-27): el adjunto no estaba disponible.

Queda pendiente guardarlo acá **tal cual**, sin editarlo, junto con `SPEC-UI-empleados.md`
(v3), que tampoco llegó.

No se generó un reemplazo: un prototipo inventado sería peor que no tenerlo — dejaría de
ser la referencia firmada y pasaría a ser una opinión más.

El piloto visual de esa sesión se hizo contra la especificación **escrita** del pase
(tokens, orden de columnas, fórmula del 10% y pie de la grilla), que sí estaba completa.
Lo que queda por contrastar contra el prototipo cuando aparezca: espaciados, tipografías y
la composición fina de cards y stats.
