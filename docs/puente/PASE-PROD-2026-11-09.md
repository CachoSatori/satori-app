## 2. Mig 081 + su fila del ledger (UNA sola transacción)
**El `081.sql` NO trae `begin`/`commit`** (auditoría A3). La 081 y su fila del ledger van juntas en un solo bloque:
o quedan las dos o ninguna. Y el `insert` del ledger **no se arma a mano** (auditoría A4: un salto de línea de más o de
menos cambia el md5): se genera con este script, en la carpeta donde están `081.sql` y `082.sql` (PowerShell 5.1):
```powershell
function Armar-Bloque($archivo, $version, $nombre) {
  $sql = Get-Content -Raw -Encoding UTF8 $archivo            # el archivo tal cual, con su salto final
  if ($sql.Contains('$m$')) { throw "el archivo contiene `$m`$" }
  $sinTx = $sql -replace '(?im)^\s*(begin|commit)\s*;\s*$', ''   # la 082 trae su propio begin/commit
  "begin;`n" + $sinTx + "`ninsert into supabase_migrations.schema_migrations (version, name, statements) values ('" +
    $version + "', '" + $nombre + "', array[`$m`$" + $sql + "`$m`$]);`ncommit;`n"
}
# WriteAllText escribe UTF-8 SIN BOM (Set-Content -Encoding UTF8 de PowerShell 5.1 agrega BOM)
[IO.File]::WriteAllText("$PWD\bloque_081.sql", (Armar-Bloque .\081.sql '081' 'pos_ndf_campos_factura'))
[IO.File]::WriteAllText("$PWD\bloque_082.sql", (Armar-Bloque .\082.sql '082' 'pos_ndf_ingesta_transaccional'))
```

se ejecuta es el mismo SQL sin los `begin`/`commit` internos, envuelto en uno solo junto con el `insert`.

## 8. Criterios de aborto → rollback (§9)
Se aborta **sin discutir** si pasa cualquiera de estos:
1. 401 en el log del agente después del deploy (y no es el caso previsto de §4.3).
2. `last_error` no nulo **dos ciclos seguidos**, o `last_poll_at` quieto **más de 5 minutos** con el local abierto.
3. **Cualquier** factura con líneas duplicadas (6.3/6.4/§7) que no se explique contra el PoS.
4. Una factura cerrada en el PoS que **no llega en 3 ciclos**, o llega con otro total o con otra cantidad de líneas.
5. `ingest-ndf: excepción` o `no se pudo guardar el lote` en los logs del Edge.
6. «Enforce JWT verification» prendido y no se puede corregir con un redeploy (§5).
7. La prueba de humo no pasa en **30 minutos** desde la primera venta.
8. **Un 5xx o un timeout del Edge en 2 ciclos seguidos** (log del agente o panel → Logs), aunque el ciclo siguiente
   entre (auditoría del 08-nov).

**Antes del deploy no hay rollback, hay parada:** si falla algo de §1–§3 (md5, columnas, grants), se para ahí. La 081 y la
082 son aditivas y el Edge de hoy no las usa: pueden quedar puestas mientras se decide.
